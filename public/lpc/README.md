# Character art

Sprite sheets from the [Universal LPC Spritesheet Character Generator](https://github.com/LiberatedPixelCup/Universal-LPC-Spritesheet-Character-Generator),
vendored by `pnpm lpc` (`scripts/lpc.ts`) from the commit recorded in
`web/map/lpc.json`. Each sheet is available under at least one of
[CC0](https://creativecommons.org/publicdomain/zero/1.0/),
[OGA-BY 3.0](https://static.opengameart.org/OGA-BY-3.0.txt),
[CC-BY 3.0](https://creativecommons.org/licenses/by/3.0/), or
[CC-BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/); the authors,
licenses, and source links for each are in `web/map/lpc.json` and on the app's
terms page. The app recolors these sheets for each person; recolored versions
of CC-BY-SA 3.0 art are shared under CC-BY-SA 3.0.
